# Sample rankings

`sample_rankings.csv` is ESPN's public default PPR board: draft rank, ADP from
ESPN's own drafts, the season projection, team and bye week for the top
300 players. It exists so the public app has something to draft with before a
visitor uploads their own file. It is not the board the owner drafts from.

Regenerate with `./venv/bin/python src/sample_rankings.py`.
